# 分发架构与历史说明

## 现行职责（2026-09-13）

`chengfeng-videocut` 主仓维护 Runtime、Studio、CLI 与总体安装入口。新安装从 [INSTALL](../INSTALL.md) 开始；公开七个独立 Skill 仓库及各自的安装说明也由该入口导航，本页不复制版本清单。

七个独立包各自维护本项方法、必要资源与依赖说明。其中 `chengfeng-videocut-install` 是安装方法的唯一真源；主 Plugin 的设计是引用其同源快照，不另维护第二套安装方法，该方案不能视为已经发布。旧 `chengfeng-videocut-skills` 仓库只提供迁移导航并保留旧代码与历史，不再作为新安装实现的维护入口。小黑动画独立包公开其方法和获列明许可的资源，不把私人小鸟或产品记录复制进主仓。

主 Plugin 的新职责是安装引导与组合清单，不批量内置业务 Skills；旧市场入口不能视为新组合的安装入口。当前安装方法不要求 MCP，不因安装某个 Skill 自动安装 Runtime 或执行业务任务。

## 已公开范围与未完成项

七包公开的 `v0.1.0-beta.1` 是文件级源码预览：包文件安装、宿主加载、Runtime 能力和真实业务结果分别验收。单包安装不代表已经取得完整工作台或整套能力。

截至上述日期，Runtime 公开 main 的软件版本仍为 `0.4.9`；本地开发版本 `0.5.9` 包含尚未发布的 CLI 改动。不能把本地命令、版本要求或验证结果套用到公开 Runtime，也不能仅凭版本号宣称兼容。

当前组合脚本仅接受明确提供的本地清单和包路径；没有已验证的远端整套一键发行。远端固定清单获取、整套下载、Runtime 安装及宿主加载闭环仍需独立实现与验收。采用确切发行时，以该版本的来源、摘要、平台及能力证据为准。
